## 建议测量顺序

1. 退出 Xcode 调试器，从固定安装路径启动 Release。
2. 空闲后记录 `scripts/measure-memory.sh` 输出。
3. 打开/关闭菜单与设置，再记录。
4. 执行一组实际切屏，再记录；区分系统缓存升高与持续线性泄漏。
5. 有问题时保留第一条完整编译错误，或菜单“查看状态与诊断…”的信息。

不要为了自动测试开启全局键盘监听、录屏、写入 Chrome 配置或模拟大量键盘事件。

## Dock 屏幕选择新增验收（2026-09-28，待真机执行）

- 默认选择内屏，原有边距数值保留；外屏选中后内屏不再额外留白。
- 两块同型号外屏：名称、逻辑尺寸和坐标可区分，分别选择并验证只有目标屏幕留白。
- 选择、退出重启、改变排列、拔插：UUID 匹配；断开时保留勾选的未连接项。
- 只有一块内屏或外屏：无论保存选择都应用边距；合盖多外屏只对选中屏幕应用。
- 修改选择不立即移动窗口；后续快捷键使用新选择，屏幕变化取消旧操作。
- 系统预留空间大于边距时取较大值；验证 0/50/500 pt、负坐标、不同缩放。
- Chrome 非前台首次只唤出；外屏仍直接返回内屏，保持既有切换顺序。
- macOS 26 和 27 分别完成菜单显示、设置保存和真实 Chrome 窗口移动验收。
