# 留白窗口 · 菜单栏图标

按用户选择的方案一设计：圆角窗口外框、左侧窄留白、右侧实心区域，无箭头。透明底单色 PNG 设计母版，由内置 image_gen 生成。

这是设计资产，尚未接入应用或完成菜单栏实际尺寸验证。preview.html 提供浅色和深色背景预览；深色图标用 CSS 反白展示。

## 完整提示词

Use case: logo-brand. Asset type: SideSpace macOS top menu bar icon, standalone monochrome transparent master. Design exactly ONE ultra-simple geometric symbol named 'margin window'. One landscape rounded rectangle outer frame in pure black. Inside that frame, a narrow transparent empty strip on the LEFT represents the intentional window margin, and one solid pure-black rounded rectangular pane fills the RIGHT interior, separated from the outer border by a consistent transparent inset gap. Outer frame aspect ratio 1.35:1, subtle rounded corners, uniform bold stroke. The inner right pane occupies about 65 percent of interior width, with a clearly readable left empty margin. Visually balanced, crisp vector-like geometry, designed to remain recognizable at 18 by 14 logical points. Center icon on square canvas, occupying about 75 percent of canvas width. Only opaque black shape and genuine transparent background and gaps, antialiasing on edges only. No arrows, no text, no letters, no extra divider line, no multiple windows, no gradients, no shadows, no tile, no 3D, no mockup, no presentation board, no watermark. Minimal native macOS utility aesthetic.
