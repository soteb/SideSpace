根据根目录 README_zh.md 的功能介绍设计，未阅读或修改实现代码。

- `SideSpace-AppIcon.png`：蓝色圆角底板与白色窗口，左侧窄条代表内屏边距，向右箭头代表窗口移动。

## 生成提示词

### 应用图标

Use case: logo-brand. Asset type: SideSpace native macOS application icon, standalone production artwork. Design a distinctive minimal premium macOS icon communicating a window fitting neatly into a display and moving right between screens. One centered rounded-square rich blue tile with subtly luminous blue gradient and restrained dimensional bevel. Inside, one bold white rounded rectangular window outline, a narrow empty inset strip on the left suggesting the intentional left margin, and a single clean right-pointing arrow integrated into the window center. Exceptionally simple coherent geometric silhouette, generous breathing room, crisp geometry, straight-on orthographic view. White symbol with very subtle material depth, not glass clutter. Tile fills about 84 percent of square canvas, transparent outside tile. No letters, no words, no Chrome logo, no screenshots, no extra objects, no mockup, no watermark. Exactly one icon, 1024x1024 composition.

### 菜单栏图标

Use case: logo-brand. Asset type: SideSpace macOS menu bar monochrome template icon master. Exactly one minimal black geometric icon on genuine transparent background. A single wide rounded rectangular window outline, with a vertical divider near its left edge forming a narrow empty left margin strip, and a clean right-pointing arrow in its main interior. Use uniform bold strokes, optically balanced spacing, rounded joins, exceptionally simple 18-point legibility. The window outline must stay fully closed and the arrow must be fully inside with generous clear space. Main proportions width 18 units height 14 units; stroke approximately 1.5 units. Center on square transparent canvas with generous padding. Flat pure black silhouette only, fully opaque black strokes and transparent holes. No tile, no gradient, no gray, no shadow, no perspective, no text, no labels, no multiple variants, no mockup, no watermark. This is the monochrome companion to a blue and white app icon for a lightweight window layout utility.
